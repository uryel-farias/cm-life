# 🏥 CM Life

Website institucional desenvolvido para uma clínica médica fictícia, apresentando informações sobre especialidades, corpo clínico e agendamento de consultas.

---

## 🔗 Acesso ao projeto

Você pode visualizar o projeto online clicando no link abaixo:  
👉 [Acessar CM Life](https://cm-life-olive.vercel.app/)

---

## 💡 Sobre o projeto

O **CM Life** foi criado com foco em praticar a construção de um site responsivo utilizando apenas **HTML e CSS**.  
O layout busca transmitir confiança e profissionalismo, características essenciais para um ambiente médico.

---

## ⚙️ Como foi feito

O desenvolvimento foi baseado em um **design simples e funcional**, estruturado em HTML semântico e estilizado com CSS puro.  
Também foram aplicadas boas práticas de responsividade para garantir uma boa experiência tanto em desktop quanto em dispositivos móveis.

---

## 🧩 Tecnologias utilizadas

- HTML5  
- CSS3  
- Git e GitHub (para versionamento e publicação)

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foi possível praticar e consolidar:
- Estruturação de páginas HTML semânticas;  
- Criação de layouts responsivos com CSS;  
- Organização de arquivos e pastas em um projeto web;  
- Publicação de sites no Vercel.
